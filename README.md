## 프로젝트 개요
- Private Blog는 그 날의 일기 및 영화 리뷰 글을 적을 수 있는 개인적인 블로그입니다.

### 핵심기능

🔒**회원 가입을 통한 커뮤니티 이용** 

**📖일기 작성**

**📖영화 리뷰 작성**
